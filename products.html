Introducing PHX-DAQ 24

At Phoenixtek Solution we build instruments for engineers who need dependable data from the field. PHX-DAQ 24 puts four 24-bit strain-gauge inputs and four temperature probe inputs on a single module. It samples each strain channel at up to 100 Hz and delivers the data over standard Ethernet using Modbus TCP.

It ships with PHX-Sense Studio, our Windows console. Find every logger on the network, watch live plots, calibrate and zero each channel, and record to CSV, across as many modules as your project needs.

It is built for unattended sites. Configuration and firmware updates are protected by a key, updates roll back automatically if something goes wrong, and each unit reports its own health and restart history.

Key features

  • 4 independent 24-bit inputs, one converter per channel, for bridge-type sensors
  • Programmable gain 1× to 128×, set per channel
  • 4 temperature inputs for NTC probes, for on-site temperature compensation
  • 1 to 100 Hz selectable output rate per channel
  • Ethernet 10/100 with Modbus TCP and a continuous data stream
  • Automatic discovery on the network; DHCP or static IP
  • Built-in Wi-Fi access point for on-site setup
  • Authenticated configuration and firmware updates
  • Network firmware updates with automatic rollback
  • Self-reporting health: uptime and restart counters
  • 24 V DC supply with input protection

PHX-Sense Studio

Windows console supplied with every PHX-DAQ 24 for setup, monitoring and recording. Requires Windows 10 or 11 (64-bit) and a network connection to the logger.

  • Automatic discovery of every logger on the network
  • Connect to one unit or many, each with its own settings
  • Live multi-channel plots and numeric readouts
  • Per-channel names, units, calibration and zero (tare)
  • Selectable digital filters
  • Recording to CSV, one file per module, with session notes and event markers
  • Sample rate, gain and channel selection per unit
  • Network setup and site access key
  • Firmware update with progress and automatic rollback
  • Unit health view: uptime and restart history

Integration with your systems

PHX-DAQ 24 exposes its measurements over standard Modbus TCP so it can be read by SCADA systems, PLCs and custom software. A continuous TCP data stream is available for high-rate acquisition.

  • The Modbus register map and stream format are provided in an integration guide issued to qualified partners on request
  • Measurement and status data can be read by any Modbus TCP client. Changing settings requires authentication
  • Only one client can hold the data stream at a time. Additional clients can read measurements through Modbus TCP
